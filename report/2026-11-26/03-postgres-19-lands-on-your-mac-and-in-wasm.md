## Summary
#​675 — November 25, 2026 Web Version Postgres Weekly Postgres.app 3.0 Brings Easy Postgres 19 to the Mac — If you're not on macOS, keep scrolling, but otherwise this is a neat release of an easy way to run Postgres on the Mac. 3.0 adds Postgres 19 and PostGIS 3.7 and has an updated UI (above) . You can grab it as a 19 only build or one that includes 14 through 19. Jakob Egger et al. 💡 Note that v3.0 has 'unbundled' some previously installed extensions like pgRouting and wal2json . These are now available as separate downloads . Stop Scanning Rows You Don’t Need — As your Postgres tables grow, queries slow down and indexing alone can only do so much. TimescaleDB automatically partitions data by time, allowing Postgres to skip irrelevant chunks and query only what it needs. Faster queries, less tuning, and the same Postgres you already know. Tiger Data (creators of TimescaleDB) sponsor Forcing a Join Order in Postgres 19 with pg_stash_advice — Postgres 19's plan advice modules give us the closest (official) thing to query hints so far. Laurenz tests a join order that takes a query from 405ms to ~10ms, stores that advice under the query ID, but also argues for using this approach sparingly. Laurenz Albe (CYBERTEC) 💡 I say 'official' because there are other ways to do similar things with extensions like pg_hint_plan which uses Oracle-like hints and now has a Postgres 19 release . IN BRIEF: If you use Docker's postgres:latest , bear in mind it's now switched to Postgres 19 . If your volume holds a v18 database, the updated container will error, and you should pin postgres:18 until you've upgraded . 🇨🇦 The popular PGConf.dev is back across May 11–14, 2027 in Montréal, and its CFP is open (until January 12). 🇸🇪 While on the other side of the pond, Nordic PGDay 2027 takes place March 16 in Stockholm. The CFP is open till January 8. Robert Haas and Jonathan Katz revisit why Postgres 19 shipped late . The Postgres Mistakes We All Still Make — Slides from a NYC meetup on mistakes or misassumptions (delightfully zero indexed!) that can show up at scale, covering MVCC quirks, open transactions, bulk deletes and unused indexes. There's also a repo with SQL showing off the problems. Scott Mead (Databricks) What's Left in Postgres 19 After the Reverts — Postgres 19 lost a variety of anticipated features late on, but what did make it? Zsolt tours the survivors. Zsolt Parragi (Percona) 📄 Squeezing Tables with Postgres 19 – The inside story of how REPACK (CONCURRENTLY) made it into v19, from the committer who fought to keep it in. Álvaro Herrera (EDB) 📄 How to Deal with Slow Postgres Shutdowns – You'd think stopping Postgres would be faster than starting it, but no, and Laurenz looks at why. Laurenz Albe (CYBERTEC) 📰 Classifieds ⚡ Already on Postgres? Rebase adds REST, a typed SDK, auth, storage, functions and cron, plus a ready admin panel. MIT licensed. RELEASES AND CODE: PGlite 0.6: Postgres 19, Compiled to WebAssembly — The WASM build of Postgres for the browser (plus Node and Bun) now runs Postgres 19, so trying out the new features in your tests, say, is only an npm install away. Persisted data from older versions needs a dump and restore . ElectricSQL 💡 No blog post yet so the link above is to the rather spartan release notes, but if you're new to PGlite the docs are a good place to start. gopgext: Write Postgres Extensions in Go — Last week we covered Rust's pgrx , now it's Go's turn! With this, you can mark Go functions with a comment and it'll build them into a Postgres extension using TinyGo with the C glue code and SQL included. It's very new and experimental, however. Jesús Espino 💡 If you're into Go, check out our sister newsletter Go Weekly :-) PgJDBC 42.7.15: Many Security Fixes for the Java/JDBC Driver — The official JDBC driver closes fourteen security advisories (six rated high) in one go with some of the bugs going back years. pgjdbc WAL-G 3.0.10 – A feature-rich release for the backup/recovery tool, including a new wal-send command that lets standbys stream WAL from backup storage. pg_parquet 0.6 – Crunchy Data's extension for copying to and from Parquet files now supports Postgres 19. 🔎 pg_textsearch 1.6 – Tiger Data's BM25 ranked text search extension also joins the Postgres 19 train, plus has some efficiency and ranking improvements. PGSync 8.0 – Postgres to Elasticsearch/OpenSearch syncing tool. Npgsql 11.0 – The ADO.NET data provider for Postgres.
