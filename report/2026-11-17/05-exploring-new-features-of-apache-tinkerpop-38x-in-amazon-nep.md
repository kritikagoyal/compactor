## Summary
Upgrading to Apache TinkerPop 3.8.x in Amazon Neptune 1.5.0.0 brings cleaner, more predictable Gremlin and a major expansion of Data Flow Engine (DFE) coverage, along with semantic changes that need review. Learn what changed, which query patterns are affected, and how to prepare for the upgrade.
