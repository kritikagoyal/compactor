## Summary
Learn how to connect Amazon RDS for SQL Server diagnostic tools to AWS DevOps Agent through Amazon Bedrock AgentCore Gateway. MCP tools run in AWS Lambda behind a governed Gateway endpoint, and an investigation skill encodes your DBA team's method so the agent can triage alarms and run autonomous, auditable database investigations.
