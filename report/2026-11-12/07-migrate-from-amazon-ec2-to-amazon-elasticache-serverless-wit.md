## Summary
On October 20, 2026, Amazon ElastiCache introduced online migration to ElastiCache Serverless for Valkey from self-managed Valkey and Redis OSS on Amazon EC2 with zero downtime. This post shows what's supported at launch, how online migration works, and how to run a migration in the ElastiCache console.
