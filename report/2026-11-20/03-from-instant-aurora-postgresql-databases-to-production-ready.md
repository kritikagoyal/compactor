## Summary
Amazon Aurora PostgreSQL express configuration now supports VPC networking. You can move an existing cluster into your VPC with a single modify operation, keeping its data and endpoint, from the console, the AWS CLI, or an AI agent. This post shows how to move and verify a cluster, and how to let an agent do it with IAM guardrails.
