## Summary
Amazon Neptune now supports tag-based access control (TBAC) for data-plane operations. This post walks through three scenarios for isolating multiple teams on a shared fleet of Neptune clusters using AWS resource tags and IAM principal tags as conditions in IAM policies and service control policies.
