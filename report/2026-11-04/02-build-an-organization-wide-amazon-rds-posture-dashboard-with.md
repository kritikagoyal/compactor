## Summary
Deletion protection on an Amazon RDS database is a single setting that anyone can switch off, and across hundreds of accounts there is no single place to see which databases still run without it. This post shows how to track Amazon RDS posture organization-wide with one Amazon CloudWatch dashboard, built and verified with Kiro.
